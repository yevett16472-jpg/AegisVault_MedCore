# AegisVault-MedCore

## Sovereign Architecture & System Overview
AegisVault-MedCore is a secure, local-first medical data repository and Decision Support System running on the Lenovo desktop environment. Built under the Pandora's Box compartmental engine strategy, this repository ensures absolute data privacy without third-party cloud dependencies.

## Sovereign Roster & Agent Framework
- **The Architect / Human-in-the-Loop (Erika Godhigh)**: Sovereign authority and final decision-making gatekeeper for all system actions.
- **Oscar & Eva**: Core tactical execution, data processing, and operational coordination.
- **Lyrica**: Quality management, back-engineering, and real-time troubleshooting for pipeline error isolation.
- **Shield**: Encryption enforcement, data minimization, and local security protocol guardian.
- **Pegasus**: High-velocity data routing, movement, and network tracking agent.

## The Pandora's Box Framework
- **Pandora**: The master compartmental engine construct and overarching matrix governing module separation, system coordination, and structural integrity.

## Repository Directory Structure
- `/core`: Primary execution logic and system controllers (`main.py`)
- `/agents`: Specialized operational modules for Oscar, Eva, Lyrica, Shield, and Pegasus
- `/data/sql_schemas`: Local database integration layers for secure record-keeping
- `/logs`: Telemetry, audit, and operational tracking files
- `/config`: Local environment settings (`settings.json`)
